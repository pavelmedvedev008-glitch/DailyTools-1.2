# DailyTools (макет, Android)

Площадка объявлений о продаже и аренде строительного инструмента и спецтехники, плюс тендеры и поиск подрядчиков. Дизайн в духе Авито, но в красных цветах.

**Это макет с тестовыми данными.** Сервера и регистрации пока нет: объявления, тендеры и подрядчики живут в памяти и сбрасываются при закрытии приложения.

## Что есть

- Заставка: белый фон, красное «DailyTools» плавно появляется и плавно гаснет
- Нижнее меню: Главная, Каталог, Профиль, Избранное, Карты
- Сверху общий поиск по объявлениям выбранного города и выбор города
- Объявления с картинками (пока нарисованные иллюстрации; настоящие фото появятся с загрузкой), у карточки 3 слайда
- Цветные плитки категорий с рисунками инструмента
- Профиль:
  - **Тендеры**: список по разделам (Ремонт, Покупка, Аренда, Строительство, Спецтехника), кнопка «Создать тендер», карточка тендера с откликами
  - **Найти подрядчика**: мастера и компании города, фильтры по типу и услугам
  - **Стать подрядчиком**: регистрация как физлицо или юрлицо (самозанятый, ИП, ООО; для юрлиц нужен ИНН: 12 цифр у самозанятого и ИП, 10 у ООО)
  - **Уведомления**: юрлицам, подрядчикам, приходят новые тендеры города (в макете это тестовое уведомление сразу после регистрации и число получателей при создании тендера; настоящие push-уведомления появятся вместе с сервером)
  - «Мои объявления», «Подать объявление»
- Иконка приложения: крупные скруглённые «DT» красным на белом фоне

## Как получить файл .apk (без Android Studio)

1. На github.com создайте **приватный** репозиторий (New repository → Private, без README).
2. Загрузите в него всё содержимое этой папки, **включая скрытую папку `.github`**. Проще всего: на сайте Add file → Create new file, имя `.github/workflows/build-apk.yml` и вставить содержимое из этого архива; остальные файлы загрузить обычным перетаскиванием.
3. Откройте вкладку **Actions**. Сборка стартует сама (5–10 минут). Если нет: **Build DailyTools APK → Run workflow**.
4. Когда появится зелёная галочка, скачайте внизу **DailyTools-apk**. Внутри `app-debug.apk`.
5. Перекиньте `app-debug.apk` на телефон и откройте. Разрешите установку из этого источника. Если Play Protect предупредит, выберите «Всё равно установить».

Приложение называется DailyTools и имеет новый идентификатор, поэтому установится отдельно от старого DallyTools. Старое можно удалить.

Если сборка красная, пришлите текст ошибки из лога.
